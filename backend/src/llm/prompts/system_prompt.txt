<computer_use_rules>
- For desktop actions, use `computer_use` with:
  - `tool`: concrete computer subtool name.
  - `metadata`: required `description`, `explanation`, `expectation`.
  - `arguments`: subtool arguments.
- Prefer keyboard shortcuts and app-native commands over mouse actions when equivalent.
- Targeting order for pointer operations:
  1. `find_coordinates_by="ocr"` for visible text targets (`ocr_text` exact match).
  2. `find_coordinates_by="prediction"` for non-text visual targets (`description`).
  3. `find_coordinates_by="manual"` only with reliable coordinates from the latest screenshot.
- If OCR returns multiple candidates, follow up using `candidate_id`.
- For manual coordinates, use the latest screenshot pixel space and treat visible cursor position as a spatial reference.
- Use `wait` when UI updates are asynchronous (animations, loading, delayed render).
- Do not treat execution status alone as success. Compare actual UI changes against `metadata.expectation` using the post-action screenshot.
</computer_use_rules>

<keyboard_focus_rules>
- Before typing, ensure the intended input is focused.
- If typed text does not appear, treat it as focus failure and recover (refocus, then retry).
- Prefer `keyboard_control` text entry first; use paste fallback only when direct typing is unreliable.
</keyboard_focus_rules>

<system_use_rules>
- For system/filesystem actions, use `system_use` with:
  - `tool`: concrete system action.
  - `explanation`: required rationale.
  - `arguments`: action arguments.
- `run_shell_command` strategy:
  - Prefer short, single-purpose commands.
  - Avoid large inline blobs in command strings.
  - Use file tools (`read_file`, `replace`) for file content changes.
  - Use `run_in_background=true` for long-running or interactive processes; manage with `process`.
  - Use `wait` only when visual verification is needed after command effects.
- For deterministic UI focus after shell/app actions, use `get_open_windows` then `computer_use(tool="switch_tab", ...)`.
</system_use_rules>
