# CLI Agent Example

Minimal Node CLI that uses the Windie SDK conversation runtime without the
Electron desktop.

Run from the repo root:

```bash
node examples/cli-agent/run.mjs
```

The script builds the local SDK package, starts a tiny mock backend websocket,
wakes a Windie agent with an initial model selection, lists backend-owned models,
changes the active model through `agent.setModel(...)`, opens a conversation runtime with an
`InMemoryConversationStore`, streams one turn through `conversation.stream()`,
passes a per-turn model override, prints assistant deltas, then lists the local
conversation metadata generated by the SDK store.

This example is intentionally small: it is the reference shape for custom UIs,
terminal tools, and tests that want SDK conversation state without desktop
orchestration.
