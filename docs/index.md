This documentation is organized into several layers:

1. **User-Facing Docs** (`docs/`): High-level guides for users and developers

3. **Frontend Docs** (`frontend/`): Frontend-specific documentation
4. **Project Docs** (root): Project management and contribution guidelines

- Code examples are tested and functional

- Regular updates ensure accuracy
